# 🛒 বাজার দর (BazarDor)

A modern web application to track daily market prices of essential commodities in Bangladesh.

## 🚀 Technologies Used
- **Next.js (App Router)** - React framework for building the UI and handling routes.
- **Tailwind CSS** - Utility-first CSS framework for styling and responsiveness.
- **TypeScript** - For type safety and better developer experience.
- **React Hot Toast** - For elegant toast notifications.
- **Lucide React** - For beautiful, consistent icons.
- **BetterAuth** - For user authentication setup.

## ✨ Key Features
1. **Real-time Price Tracking:** Get the latest market prices for various categories like Rice, Dal, Vegetables, Meat, Fish, etc.
2. **Interactive Marquee Ticker:** A live price ticker showcasing quick updates of product prices and changes directly below the navbar.
3. **Category Filtering & Sorting:** Browse products by categories and sort them by price (Default, Low to High, High to Low).
4. **Detailed Market Insights:** View detailed price comparisons across different markets and divisions for individual products.
5. **Authentication System:** Secure Sign In and Sign Up flows with a personalized User Profile and profile updating options.
