# 🛒 বাজার দর (BazarDor)

A modern, high-performance web application to track and compare daily market prices of essential commodities in Bangladesh.

## 🚀 Technologies Used
- **Next.js (App Router)** — React framework for server-side rendering, dynamic routing, and fast client navigation.
- **Tailwind CSS** — Utility-first styling for a clean, modern, and responsive user experience.
- **TypeScript** — Strongly typed architecture for maximum reliability and maintainability.
- **BetterAuth & MongoDB Atlas** — Secure authentication and session management with email/password, Google OAuth 2.0, and GitHub OAuth 2.0.
- **React Hot Toast** — Instant, elegant user feedback and notifications.
- **Lucide React** — Crisp, clean iconography.

---

## ✨ Key Features
1. **Real-time Price Tracking:** Instant visibility into daily market prices for essential grocery categories (Rice, Dal, Oil, Vegetables, Fish, Meat, Eggs, Spices).
2. **Interactive Marquee Ticker:** Live auto-scrolling ticker bar directly below the navbar displaying current prices, units, and price movements (▲/▼).
3. **Category Filtering & Bengali Numeric Sorting:** Seamlessly browse products by category with price sorting (Default, Low to High, High to Low) handling Bengali currency figures accurately.
4. **Detailed Market Insights (Protected Route):** In-depth market breakdown for individual products showcasing minimum, maximum, and average prices across various local markets and divisions.
5. **Comprehensive Authentication & Profile Management:** Complete login/signup flows via credentials, Google, and GitHub, along with a user profile page and personal information update capabilities.
